# EPYALINK — atualização do cabeçalho

- Substituído o botão de três pontos `⋮` por menu hambúrguer `☰`, no estilo de navegação móvel conhecido pelos utilizadores de redes sociais.
- O seletor de idioma `🌐` permanece imediatamente ao lado do menu.
- Mantidos os identificadores JS existentes para não quebrar as rotinas do menu institucional.
- Ao mudar de menu interno, o menu hambúrguer é fechado sem remover o botão do cabeçalho.
- Mantidas as correções anteriores de cadastro com fotografia e sistema multilíngue.
